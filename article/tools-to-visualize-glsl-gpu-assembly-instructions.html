Tools to Visualize GLSL GPU Assembly Instructions

Compiling OpenGL Shading Language (GLSL) into vendor-specific GPU Instruction Set Architecture (ISA) code is essential for low-level performance optimization. Because modern GPUs from AMD, NVIDIA, and Intel employ proprietary microarchitectures, visualizing the target hardware instructions requires specialized tools capable of disassembling compiled shaders and mapping instructions directly back to your source code.

AMD Radeon GPU Analyzer (RGA)

AMD Radeon GPU Analyzer (part of the Radeon Developer Tool Suite) is one of the most comprehensive offline compilers and ISA visualization tools available.

  • How it works with GLSL: RGA compiles high-level GLSL targeting Vulkan or OpenGL without requiring specific hardware installed on the host development machine.
  • Visualization capabilities: It generates disassembled AMD GCN and RDNA ISA listings side-by-side with your original GLSL code. It also outputs control-flow graphs, vector/scalar general-purpose register (VGPR/SGPR) pressure analyses, and stall cycle estimations.

Radeon GPU Profiler (RGP)

While RGA operates offline, AMD’s Radeon GPU Profiler works dynamically on runtime frame captures.

  • How it works with GLSL: When capturing Vulkan or OpenGL workloads, RGP extracts the finalized shader binaries directly from the driver.
  • Visualization capabilities: The Instruction Timing view maps raw hardware ISA instructions to specific hardware stages, wave states, and execution latencies, highlighting memory bottlenecks and register spilling directly within the context of a drawn frame.

NVIDIA Nsight Graphics

NVIDIA Nsight Graphics is the primary suite for profiling and debugging graphics workloads on NVIDIA hardware.

  • How it works with GLSL: By capturing a frame from an OpenGL or Vulkan application, Nsight Graphics reconstructs the pipeline and extracts the proprietary compiled assembly, known as SASS (Streaming Assembler), along with intermediate PTX (Parallel Thread Execution) code.
  • Visualization capabilities: The Shader Profiler view provides an interactive, side-by-side breakdown of the original GLSL source, intermediate SPIR-V, and the final compiled SASS instructions. It includes per-instruction execution metrics, register allocations, warp stall reasons, and memory access latency data.

Compiler Explorer (Godbolt)

Compiler Explorer is a widely used web-based compilation tool that includes strong support for shader languages.

  • How it works with GLSL: Using backends like glslang and drivers like AMDVLK or specialized compilation targets, you can compile GLSL directly in the browser.
  • Visualization capabilities: When configured with an appropriate backend (such as AMDVLK for AMD targets), Compiler Explorer highlights matching lines between high-level GLSL source and the emitted target ISA, making it ideal for quick instruction counting and algorithmic comparisons without local tool installation.

Intel Graphics Performance Analyzers (Intel GPA)

Intel GPA allows developers to optimize graphics workloads across Intel integrated and discrete GPUs, such as Intel Arc.

  • How it works with GLSL: Through the Graphics Frame Analyzer component, Intel GPA inspects compiled shaders originating from Vulkan or OpenGL draw calls.
  • Visualization capabilities: It exposes Intel's GEN ISA disassembly, displaying instruction-level latency, execution unit (EU) port usage, SIMD utilization modes (e.g., SIMD8 vs. SIMD16), and register consumption.

SPIR-V Disassembly: An Intermediate Bridge

Because modern GLSL is compiled to SPIR-V before the hardware driver converts it into final machine code, tools like spirv-dis (from the Vulkan SDK) and SPIRV-Cross play a supplementary role. While SPIR-V is a standardized intermediate representation rather than native machine ISA, inspecting it is often the first step in diagnosing compiler optimization issues before evaluating final hardware-specific microcode in tools like RGA or Nsight.
